## 📋 Descripción

Aplicación web temática de fútbol desarrollada durante las **prácticas profesionales en Datacontrol Tecnología de la Información** (Málaga), utilizando el framework **DataFlex 25.5**.

El proyecto implementa un sistema de gestión de jugadores, equipos y posiciones con navegación completa, operaciones CRUD y un sistema de datos semilla basado en el **Mundial 2026**.

---

## ✨ Funcionalidades

- 🔄 **CRUD completo** — alta, consulta, edición y baja de registros
- ⚽ **Relaciones N:M** jugador ↔ posición con UI de transferencia de listas (doble lista interactiva)
- 🗑️ **Baja lógica** de jugadores mediante escritura directa de NULL vía SQL (`despedir`)
- 🎨 **Theming CSS personalizado** — tema corporativo con estética retrowave
- 🧭 **Navegación DDO** — framework de objetos de datos de DataFlex
- 🌍 **Seed data** del Mundial 2026 — jugadores y equipos reales como datos de prueba
- 🌿 **Workflow Git** con feature branches y SourceTree

## 📁 Estructura del proyecto

```
Futbol-Webapp/
├── AppHtml/        # Vistas y plantillas HTML
├── AppSrc/         # Código fuente de la aplicación DataFlex
├── DDSrc/          # Definiciones de datos (Data Dictionary)
├── Data/           # Base de datos y seed data (Mundial 2026)
├── IdeSrc/         # Configuración del entorno DataFlex IDE
├── Programs/       # Programas y lógica de negocio
└── futbol.sws      # Workspace DataFlex
```

## 🔭 Contexto

Proyecto desarrollado íntegramente durante el período de **prácticas FCT** en [Datacontrol Tecnología de la Información](https://www.datacontrol.es), empresa especializada en soluciones DataFlex con más de 30 años de trayectoria.

El proyecto fue diseñado para aprender el framework desde cero: configuración del workspace, modelo DDO, navegación entre vistas, gestión de relaciones complejas y personalización visual.
